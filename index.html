# ♻️ RE-VEST - Moda Circular ## Descripción RE-VEST es una tienda virtual de ropa de segunda mano que busca fomentar la moda sostenible y el consumo responsable. Su objetivo es conectar personas que desean comprar prendas económicas con personas que quieren vender ropa que ya no utilizan. ## ¿Qué hace el proyecto? - Muestra un catálogo de ropa de segunda mano. - Permite buscar prendas por nombre. - Filtra productos por categorías. - Ordena los productos por precio. - Permite guardar prendas favoritas. - Cuenta con un carrito de compras. - Calcula automáticamente el total de la compra. - Permite publicar nuevas prendas. - Muestra estadísticas de reutilización e impacto ambiental. - Guarda los datos en el almacenamiento local del navegador. ## Tecnologías utilizadas - HTML5: estructura de la aplicación. - CSS3: diseño visual y adaptación a dispositivos móviles. - JavaScript: funcionalidades e interactividad. - LocalStorage: almacenamiento de información. - Google Fonts: tipografías. ## Estructura del proyecto re-vest/ │ ├── index.html ├── README.md └── .gitignore ## Cómo ejecutar el proyecto 1. Clonar el repositorio: git clone URL_DE_TU_REPOSITORIO 2. Entrar a la carpeta: cd re-vest 3. Cambiar a la rama principal: git checkout main 4. Abrir el archivo index.html en un navegador. También se puede ejecutar utilizando la extensión Live Server de Visual Studio Code. ## Funcionamiento El usuario puede explorar el catálogo, buscar productos, filtrar por categorías, agregar prendas a favoritos y añadir productos al carrito. También puede publicar prendas usadas mediante un formulario. La aplicación utiliza LocalStorage para guardar los datos en el navegador, permitiendo conservar la información entre sesiones en el mismo dispositivo. Las compras son simuladas y no procesan pagos reales. ## Ramas de Git - main: contiene la versión funcional de producción. - develop: contiene el desarrollo y las mejoras del proyecto. Todos los cambios y nuevas funcionalidades se desarrollan primero en la rama develop. ## Objetivo del proyecto Promover la economía circular, reducir el desperdicio textil y demostrar cómo la tecnología puede ayudar a construir hábitos de consumo más sostenibles. ## Autor Proyecto académico de desarrollo web.
